# Vault-0

Obsidian vault and ops memory. Two clones — one on the VPS, one on the MacBook — kept
in sync only through this GitHub remote. Pull before reading, push after writing.

Where to start, by what you need:

- **[core-index.md](core-index.md)** — ops entry point. Always-load pages, active
  services, key paths, agent roster. Start here.
- **[index.md](index.md)** — wiki catalog. Entities, concepts, topics, sources.
- **[WIKI_SCHEMA.md](WIKI_SCHEMA.md)** — authoritative page formats and frontmatter.
- **`system/`** — internal ops knowledge: projects, workflows, runbooks, decisions,
  configs, logs. Conventions in `system/cheatsheets/obsidian-conventions.md`.
- **`wiki/`** — external knowledge, ingested and linked.
- **`raw/`** — unprocessed captures. Never edited by hand.
- **`notion/`** — one-way mirror of Notion. Never read as a reference source.
