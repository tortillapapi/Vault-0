[[system/workflows/peer-orchestrator-protocol]]. These pages are copy-paste
conveniences and optional payloads — if one ever disagrees with the protocol, the
protocol wins.

- [[templates/completion-marker|completion-marker]] — canonical `.done` marker shape.
